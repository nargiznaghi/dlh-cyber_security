# Identity at Scale

- **Module:** IAM Audit & Modernization
- **Context:** MedDefense Health Systems post-incident identity security hardening.

## Core Objectives
1. **SAML 2.0 SSO:** Configure and analyze federated single sign-on assertions and role attributes.
2. **Cloud IAM:** Remediate over-privileged AWS IAM roles and least-privilege resource policies.
3. **JIT Credentials:** Implement HashiCorp Vault dynamic database secrets to replace standing privileged accounts.
4. **Automated Audit Script:** Process account directories and generate severity-scored JSON findings for executive review.
