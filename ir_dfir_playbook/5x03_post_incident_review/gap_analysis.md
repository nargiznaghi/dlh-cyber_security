## Priority summary

- **GAP-001** (P1): Credential theft via `ms0365-support.login-verification.click` went fully undetected; a proxy alert rule and domain-age blocking would have flagged the harvesting attempt at the earliest stage.
- **GAP-002** (P1): Foreign-IP VPN access (`45.63.9.88`) is the point where a single control — conditional MFA without compliant device exemptions — would have stopped the entire intrusion chain.
- **GAP-003** (P1): Proxied execution via `MSBuild.exe` running `update.xml` was permitted; locking down developer LOLBins prevents arbitrary code execution in standard user contexts.
- **GAP-004** (P1): Outbound C2 traffic to Tor exit node `185.220.101.47` persisted; automated perimeter blocking stops command-and-control communication in real time.
- **GAP-006** (P1): Unrestricted workstation-to-workstation routing permitted lateral movement from `WST-WS-031` to `WST-WS-017`; microsegmentation stops internal propagation and contains the blast radius.
