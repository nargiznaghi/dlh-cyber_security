# Windows Fortress - Active Directory Hardening Project

## Project Overview
This project focuses on auditing and hardening the `meddefense.local` Active Directory environment on Windows Server 2022 (DC01).

## Included Tasks
- **0-domain_baseline.ps1**: Active Directory Domain Reconnaissance Baseline.
- **1-domain_findings.ps1**: Active Directory Security Findings Extractor.
- **domain_security_findings.json**: Exported structured security findings report.
